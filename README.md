# TitanChatX

**Chat. Play. Dominate.**

TitanChatX is an Android messenger with built-in games: Titan AI, end-to-end encrypted secret chats, Recall for deleted messages, friend duels, and a Titan Coins shop.

## Download

[**Download the latest APK**](https://github.com/Devasena-K09/TitanChatX-Releases/releases/latest/download/TitanChatX.apk)

Current version: **v3.11.1**. Android only.

## How to install
1. Open this page on your Android phone and download the APK.
2. Open the file. If Android asks, allow "Install unknown apps" for your browser.
3. Tap Install. If Play Protect shows a warning, choose "Install anyway" only if you got this link from us.
